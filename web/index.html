01 · FIRST-TIME SETUP

Trusted firmware signer

Install the OTAFIX 2.4.12 bootloader ZIP, then the matched bootstrap application ZIP locally first. Older 0.4.0/0.4.1 applications are not the matched pair. Create a signing key on this Pi, then provision its public key and confirm the RAK15001 slot C pairing using the target’s local USB console. The private key stays on the Pi.

These setup commands are deliberately unavailable over LoRa. Keep a private backup of the Pi’s signing key.

03 · SEND THROUGH THE MESH
Target and connection
Use a companion radio connected to this Pi. The target must already have a learned direct or repeater route in its contacts, with pm ota status reporting pair=1 boot=1 flash=2097152.
A detected RAK port may belong to another device. Confirm it is your companion before sending; the page never probes a serial port automatically.
The first button does not install the image. Activation resets the remote repeater after verification and reply delivery. Full-image LoRa transfers can take hours.
