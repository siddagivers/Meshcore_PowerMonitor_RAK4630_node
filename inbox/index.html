Connecting to the service…

One service reads the radio. Telemetry, chat and OTA requests take turns; OTA waits for the current telemetry request to finish. Messages continue to be received while other requests are waiting.

Inbox

Messages and acknowledgment events are displayed; telemetry is hidden from this inbox. History stays on this Pi across restarts. Delivery acknowledgments appear as separate events; acceptance by the companion does not prove delivery.

Send a message
